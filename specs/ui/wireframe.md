# Wireframe

Split into individual `.puml` files in `wireframe/`:

- [Main](wireframe/main.puml) — persistent page (topbar, main, sticky bottom, start/stop)
- [Experiment Setup](wireframe/experiment-setup.puml) — values + pendulum
- [Setting Modal](wireframe/modal-setup.puml) — list of variables
- [Variable Modal](wireframe/modal-variable.puml) — per-variable editor
- [Angle Modal](wireframe/modal-angle.puml) — upside-down protractor visual
- [Bob Selection Modal](wireframe/modal-bob-selection.puml) — three cards on one row
